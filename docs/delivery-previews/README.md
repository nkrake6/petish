# Shipment presentation samples

These screenshots use the rendered 0.7.0 customer shipment component and the
real Petish email header, footer, logo and styles. They show illustrative item
names, carrier labels and tracking numbers. They contain no real order or
customer data and do not demonstrate a live DSers/carrier connection.
